# 安全部署检查

## 必须检查

- 首次初始化使用唯一管理员账号和至少 10 位密码。
- 持久化并限制 `.gofi-jwt-secret`、`gofi.db` 和备份文件的访问权限。
- 公网部署使用 HTTPS，并由受维护的反向代理终止 TLS。
- `GOFI_ALLOWED_ORIGINS` 只包含实际站点的完整 Origin。
- 只有确实转发请求的代理进入 `GOFI_TRUSTED_PROXIES`。
- 保持 API 和登录限流开启。
- 访客列表、预览、下载、上传和删除权限按最小权限开放。
- 日志、故障报告和截图中移除 Token、Cookie、本地路径和账号信息。

## 索引

文件索引默认启用，可通过 `GOFI_ENABLE_INDEX=false` 关闭。关闭或索引损坏不会影响普通文件浏览；管理员可以调用重建接口重新生成。只有不超过 64 KiB 的文本文件会进入内容索引。

## 漏洞报告

不要在公开 Issue 中披露可利用细节。优先使用 GitHub Security 的私密报告入口；不可用时先私下联系维护者。
