# Gofi 功能现状矩阵

本文记录 M3 完成后的可用能力和已知限制。它用于防止文档把规划误写成现状，不替代独立安全审计。

- 基线提交：`32d4a107341531119a6a7b794e9c93625a954b3b`
- 复核日期：2026-07-31

## 状态定义

| 状态 | 含义 |
| --- | --- |
| 可用 | 主流程已实现，并有对应自动化或构建验收 |
| 部分可用 | 主流程可用，但存在已记录的容量、体验或恢复限制 |
| 待验证 | 本地实现已完成，仍需要远端或其他平台验证 |
| 未实现 | 当前版本没有完整实现 |

## 用户与配置

| 能力 | 状态 | 当前实现 | 已知限制 |
| --- | --- | --- | --- |
| 首次初始化 | 可用 | 用户自行设置管理员账号和至少 10 位密码，可选存储目录；重复初始化返回 409 | 暂不支持多管理员 |
| 登录、退出 | 可用 | bcrypt、Bearer Token 与 HttpOnly Cookie；退出后撤销旧会话 | 暂无会话设备列表 |
| 旧密码迁移 | 可用 | 旧 MD5 密码在成功登录后自动升级为 bcrypt | 只有实际登录的旧账号会升级 |
| 修改密码 | 可用 | 校验当前密码和新密码策略，完成后撤销旧 Token | 修改后需要重新登录 |
| 环境变量配置 | 可用 | JWT、限流、Origin、可信代理和日志均有文档化入口 | 修改环境变量后需要重启 |
| 中英文切换 | 可用 | 前后端翻译键配对检查已纳入测试 | 品牌名和文件原始内容不翻译 |

## 文件访问与管理

| 能力 | 状态 | 当前实现 | 已知限制 |
| --- | --- | --- | --- |
| 目录浏览 | 可用 | 统一安全存储入口、点文件隐藏、访客权限校验 | 超大目录仍是一次性读取 |
| 文件详情与预览 | 部分可用 | 图片、音视频、PDF、文本和代码查看器；独立访客预览权限 | 大文本、未知编码和浏览器解码能力仍有限 |
| 文件下载 | 可用 | GET、HEAD、Range 和独立访客下载权限 | 暂无下载审计记录 |
| 当前目录过滤 | 可用 | 前端名称过滤、网格与列表视图 | 不持久化个人视图偏好 |
| 跨目录搜索 | 可用 | SQLite 文件名、路径和小文本索引；启动重建和写操作增量刷新 | 文本正文仅索引 64 KiB 以内文件 |
| 普通上传 | 可用 | 多文件、覆盖确认、临时文件和原子替换；失败时清理中间文件 | 小文件不额外计算内容哈希 |
| 删除文件或目录 | 可用 | 统一路径边界；删除内部符号链接不会跟随到目标 | 暂无回收站 |
| 分片上传 | 可用 | 大文件自动使用磁盘会话、分片与整文件 SHA-256；重启后可续传，过期会话自动清理 | 浏览器计算整文件哈希时受本机内存约束 |
| 新建目录、重命名、复制、移动 | 可用 | 前后端入口、统一冲突语义、跨设备移动回退和失败清理 | 暂无回收站和历史版本 |
| 批量操作 | 可用 | 后端最多 100 项并返回逐项结果；前端支持批量选择与删除 | 前端批量复制和移动仍按单项入口执行 |
| 分享 | 可用 | 可过期、可撤销、数据库只存令牌哈希，目录子路径受服务端限制 | 链接持有人在有效期内可访问分享范围 |

## 权限与安全

| 能力 | 状态 | 当前实现 | 已知限制 |
| --- | --- | --- | --- |
| 访客权限 | 可用 | 列表、预览、下载、上传、删除分别配置，前后端使用同一能力语义 | 当前仅有全局访客策略 |
| 路径隔离 | 可用 | 集中处理穿越、相似前缀和逃逸符号链接 | 不提供存储根目录外的挂载白名单 |
| HTTP 语义 | 可用 | 认证、权限、输入、冲突和服务错误使用真实 4xx/5xx，并返回稳定数字码和 Trace ID | 保留兼容响应包裹 |
| CORS 与 CSRF | 可用 | 完整 Origin 精确匹配，写操作校验 Origin/Referer | 反向代理必须正确配置可信来源 |
| 限流 | 可用 | API 按来源 IP 限流，登录接口每分钟最多 5 次 | 进程内计数，不适用于多节点共享 |
| 日志隐私 | 可用 | 请求日志不记录请求体、密码、Token、Cookie | 运维仍需保护日志文件本身 |

## 工程化与发布

| 能力 | 状态 | 当前实现 | 已知限制 |
| --- | --- | --- | --- |
| 本地开发与检查 | 可用 | 固定工具链并提供 `make install/dev/test/check/build/smoke` | 其他主机兼容性依赖贡献者反馈 |
| 前端测试 | 可用 | 类型检查、42 个测试和生产构建；覆盖路由、会话、权限、上传任务和 i18n | 复杂查看器仍以构建和人工行为为主 |
| 后端测试 | 可用 | 单元、HTTP 集成和 race 测试；覆盖认证、权限、路径、续传、文件操作、索引、分享和迁移 | 大文件压力与多文件并发仍待补充 |
| 前端构建 | 可用 | Shiki 仅按需加载选定语言和主题，JavaScript 引擎不携带 WASM | 新语言需显式登记 |
| 数据迁移与恢复 | 可用 | schema 版本、旧库升级测试、完整目录备份脚本和回滚文档 | 正式发布前仍需使用真实生产备份演练 |
| 单二进制发布 | 可用 | 前端嵌入、纯 Go SQLite、无 CGO 双架构构建、校验文件和启动冒烟已接入统一命令 | 远端发布流程仍未执行 |
| Docker | 可用 | amd64/arm64 分别在原生 Runner 使用普通 Docker 构建并冒烟，再合并发布清单；amd64 已本机验证 | linux/arm64 与多架构发布等待 GitHub Runner |
| CI | 待验证 | 日常检查、原生双架构产物和 Docker 工作流已定义，不依赖 Buildx/QEMU | 按维护者要求尚未推送，远端结果未知 |

## 后续边界

M2 文件管理与 M3 搜索分享已经完成。M4 负责最终多架构、升级演练与发布验收；尚未由真实环境验证的项目必须保留为待验证状态。
